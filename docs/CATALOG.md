# Chart catalogue

82 charts: the 77 charts of the reference list (Datylon's chart guide) plus five EDA extras (mosaic, Q-Q plot, pair plot, joint plot, cluster map). Every chart accepts `backend=` (`matplotlib`, `seaborn`, `plotly`) and `theme=`. *seaborn* in the backends column means a seaborn-native drawing path; every matplotlib chart also accepts `backend="seaborn"`.

## 1. Comparison

|---|---|---|---|---|---|
| [bar](../gallery/comparison/bar.png) | `pc.bar` | matplotlib, seaborn, plotly | bar chart, bar graph, horizontal bar chart | Compare values across categories; long labels; values of similar magnitude. | More than ~30 bars, or a value axis that cannot start at zero. |

| [lollipop](../gallery/comparison/lollipop.png) | `pc.lollipop` | matplotlib, plotly | lollipop plot, lollipop chart | A lighter bar chart for many categories. | Values very close together - bars are easier to compare. |
| [bullet](../gallery/comparison/bullet.png) | `pc.bullet` | matplotlib, plotly | bullet graph, bullet chart | Benchmark one actual value per metric against a target and qualitative ranges. | Anything that is not performance-vs-target data. |

| [nightingale](../gallery/comparison/nightingale.png) | `pc.nightingale` | matplotlib, plotly | nightingale's graph, nightingale rose chart, rose diagram, coxcomb chart, polar area chart, nightingale chart | Cyclic categories (months, directions) where a striking form is wanted. | Precise comparison; similar-valued sectors. |
| [waterfall](../gallery/comparison/waterfall.png) | `pc.waterfall` | matplotlib, plotly | flying bricks chart, mario chart, bridge chart, cascade chart, waterfall chart | Show how positive/negative changes build from a start value to an end value. | When absolute values of each item matter more than their contribution. |

| [small multiples](../gallery/comparison/small_multiples.png) | `pc.small_multiples` | matplotlib, plotly | small multiples chart, trellis chart, lattice chart, panel chart, facet grid, small multiple | Split a cluttered chart (spaghetti lines, many groups) into a grid of simple ones. | Too little space for each panel, or when one chart tells the story. |
| [word cloud](../gallery/comparison/word_cloud.png) | `pc.word_cloud` | matplotlib, plotly | tag cloud, word collage, wordle, word cloud | A quick, approximate overview of the most frequent words in a text. | Anything needing exact frequencies - word area is a poor value encoding. |
| [slope](../gallery/comparison/slope.png) | `pc.slope` | matplotlib, plotly | slopegraph, slope chart, slope graph | Change between exactly two time points / conditions for several categories. | More than two measurement points. |

| [quadrant](../gallery/comparison/quadrant.png) | `pc.quadrant` | matplotlib, plotly | quadrant chart, 4-quadrant matrix chart, magic quadrant, swot matrix | Benchmark items on two dimensions split into meaningful regions (e.g. SWOT). | When the split thresholds are arbitrary or forced. |
